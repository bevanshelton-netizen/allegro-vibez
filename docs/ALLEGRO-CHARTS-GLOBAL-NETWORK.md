# ALLEGRO-VIBEZ Charts + Global Music Network

## Product decision
ALLEGRO-VIBEZ becomes an artist operating system plus an independent global discovery, chart, marketing and opportunity network.

Core modules:

1. **ALLEGRO-VIBEZ CHARTS** — genre-specific Top 20 charts plus a cross-genre Global Top 20.
2. **ALLEGRO-VIBEZ AWARDS** — verified #1, sustained chart run, milestone, global breakthrough, annual and fan-choice recognition.
3. **RADIO WORLD** — structured international radio-station directory, airplay exchange, submissions, syndicated shows and premieres.
4. **FESTIVAL WORLD** — festival/showcase directory, artist-fit matching, deadlines, submissions and booking pipeline.
5. **PROMO COMMAND CENTRE** — EPK, radio one-sheet, festival pitch, press release, social campaign, smart links, QR, fan capture and campaign analytics.

## Chart integrity model
Chart positions must be generated from verified signals and a published ruleset. A proposed baseline score can combine:

- 30% verified ALLEGRO-VIBEZ listening / completion activity
- 20% verified radio airplay
- 15% saves / follows / repeat engagement
- 15% verified fan voting
- 10% bookings / live activity
- 10% cross-territory audience growth

The weights are configurable by chart committee and should be published before a chart period starts. No artist can directly buy a chart position. Paid advertising may increase legitimate discovery, but artificial streams, bot traffic, manipulated voting and other fraudulent activity are excluded.

For a launch version, every chart period should retain a calculation snapshot so that historical positions can be audited and reproduced.

## Awards ladder
- **ALLEGRO-VIBEZ #1** — verified #1 position.
- **Chart Run Award** — sustained chart presence for a published duration.
- **Gold / Platinum / Diamond Chart Status** — cumulative verified chart-performance milestones.
- **Global Breakthrough** — verified multi-territory growth.
- **African Artist of the Year** — annual published-criteria award.
- **Fan Choice** — fan-voted award kept separate from data-driven awards.

Awards should issue a unique certificate/award ID and retain the underlying chart period, genre, territory, artist and verification record.

## Radio World
Partner records should include:

- station name and country/territory
- city/time zone
- genres and subgenres
- audience description
- public submission route
- programmer/DJ contact where publicly provided
- format and technical requirements
- airplay opportunity type
- syndication opportunity
- premiere/interview opportunity
- partnership status
- last contact / next action
- artist submissions and outcomes

Target partnership formats:

- ALLEGRO-VIBEZ music exchange
- reciprocal artist discovery
- syndicated chart show
- weekly African music spotlight
- DJ mix exchange
- new-release premiere
- artist interview exchange
- festival/radio co-promotion
- branded special programming

Reference examples show that global radio partnerships can be structured around station networks, syndicated shows, artist submissions and sponsorships; ALLEGRO-VIBEZ should use the same operational discipline while keeping its own identity and rights controls.

## KORA NETWORK connection
ALLEGRO-VIBEZ is the music/business layer. KORA NETWORK is the TV/video/entertainment layer. The shared media engine should let one approved release flow into:

ALLEGRO-VIBEZ profile → radio servicing → chart tracking → KORA video consideration → interviews → short-form content → live opportunities → sponsor/brand opportunities.

No automatic KORA broadcast claim should be made until a real KORA integration or editorial acceptance path is implemented and verified.

## Commercial model
The existing artist-first commercial model remains:

- Self-Service: artist 90% / ALLEGRO-VIBEZ 10%
- Growth: artist 85% / ALLEGRO-VIBEZ 15%
- Managed Artist: artist 80% / ALLEGRO-VIBEZ 20%

Third-party deductions, taxes, refunds and agreed direct costs remain separately disclosed before calculating the artist's distributable share.

## External validation targets
The platform should pursue structured collaboration rather than generic mass email. Current research identifies useful ecosystem models including WOMEX, SXSW, global independent radio coalitions, international radio partnerships and festival/showcase opportunity directories. These are targets/reference models, not claimed ALLEGRO-VIBEZ partners.
